# goal-lock

Check the idea against:
1. Is it a **hands-on test or build** with a visible result (not news, not a listicle of links)?
2. Does it fit the audience (beginners/side-hustlers who want to make things with AI)?
3. Is there **search or competitor proof** (a tracked competitor or vidIQ data shows demand in the last 60 days)?
4. Can Max make it with free/owned tools in about one week?
5. Does it give an honest verdict?
Answer: **On goal** (5/5), **One fix away** (name the fix), or **Off goal** (why). One line each.
