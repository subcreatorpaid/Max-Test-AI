# script-qa

Check `videos/<slug>/script.md` and report a short pass/fail list:
1. Result shown and promise said in 0-5 s; no greeting.
2. Belief challenge + open loop by 0:25; re-hook every 35-45 s (list timestamps).
3. Each chapter answers one question; one honest problem + fix included; verdict present.
4. Every claim has a `facts.md` row or a `[CHECK]`; no invented numbers.
5. Disclosures: AI host line; affiliate/sponsor lines.
6. Word count 1,200-1,800; sentences short; no never-list words (`brain/brand.md`).
7. Visual cue every 2-3 sentences.
Fix what fails, then hand to the director.
