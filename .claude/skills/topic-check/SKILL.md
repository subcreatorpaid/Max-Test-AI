# topic-check

Start: `git pull`, read `CLAUDE.md`, `brain/rules.md`, `brain/status.json`. End: `python scripts/guard.py`, one commit, push, one log file in `brain/log/`, any ask for Hammad in `brain/status.json -> approvals`.

## Job
Score it 0-5 on peg, loss, demand (x2 each), gap, fact depth, visual fit, evergreen (x1) per TOPIC-FINDER section 4; add it to `documentary/topic-finder/topics.json`; run `score.py`; report rank and what to verify.
