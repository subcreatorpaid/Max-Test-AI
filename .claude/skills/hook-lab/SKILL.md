# hook-lab

For the brief's promise:
- 3 hooks (first 5 s spoken + what's on screen): one result-first ("This whole video was edited by Claude."), one doubt ("Everyone says AI can't edit. I tested it."), one stakes ("I saved 3 hours. Here's the catch.").
- 3 titles < 60 chars, different angles (test / how-to / verdict).
- 3 thumbnails: Max's expression + the result + 2-3 words that add to, not repeat, the title.
Mark a favourite set and why. No hype words.
