# storyteller

Start: `git pull`, read `CLAUDE.md`, `brain/rules.md`, `brain/status.json`. End: run `python scripts/guard.py`, one commit, push, write one log file in `brain/log/`, put any ask for Hammad in `brain/status.json -> approvals`.

## Job
Write `videos/<slug>/story.md`:
1. **The question** the viewer wants answered (e.g. "Can Claude really edit my video?").
2. **Stakes:** what they lose doing it the old way (time, money, quality).
3. **Arc:** setup (the result, 0-5 s) -> doubt (belief challenge) -> attempt -> one real problem -> fix -> result -> verdict.
4. **Open loops:** at least 3, each opened before it is closed, one every 35-45 s ("but the export broke, and the fix surprised me").
5. **Max moments:** where Max reacts on camera (max 3-4), with the emotion (surprised / sceptical / pleased).
6. **Payoff:** the verdict line, and the tease for the next video.
Rules: honest, no hype (see `brain/brand.md` never-list). The failure moment is required: it builds trust.
