# director

Start: `git pull`, read `CLAUDE.md`, `brain/rules.md`, `brain/status.json`. End: `python scripts/guard.py`, one commit, push, one log file in `brain/log/`, any ask for Hammad in `brain/status.json -> approvals`.

## Job
1. Storyboard: pictorial panels, one still + one voice line per paragraph (`videos/<id>/storyboard`). **Gate 3.**
2. Shot list for the renderer: a visual change every 6-10 s, number card or chart on every key figure, PART card every act, layouts rotate, pace changes (nothing over ~90 s at one speed).
3. Before Hammad sees a cut: quality gate in `docs/video-process.md` step 8b (contact sheet every 0.75 s, fresh reviewer, max 3 rounds).
