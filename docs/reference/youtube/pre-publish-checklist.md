# Pre-publish checklist (publisher runs this before Gate 5; guard re-checks)

Adapted from claude-youtube `sub-skills/metadata.md` (MIT) and merged with our rules. Limits from `seo-playbook.md` are REPORTED: re-check on YouTube Help if one looks off.

## Packaging
- [ ] Title under 60 chars, search phrase in the first 40, wallet stake in the title (packager rule)
- [ ] Thumbnail text 2-3 words, never repeats the title; 3 thumbnails ready for Test & Compare
- [ ] Thumbnail promise matches the hook (hook-lab winner)

## Description
- [ ] Search phrase inside the first 25 words; first 2 lines work alone (they show before "Show more")
- [ ] Under 5,000 characters
- [ ] Chapters start at 0:00, at least 3, each at least 10 s, written as searches
- [ ] Sources list with dates; recreated headlines credit the outlet
- [ ] "Not financial advice" line
- [ ] 3 hashtags at the end (never more than 15 in total, or YouTube ignores all of them; none in the title)
- [ ] 3-5 tags only (tags matter little now: spend under a minute)

## Settings
- [ ] "Altered or synthetic content" ticked (AI voice, AI/recreated images)
- [ ] Not made for kids; category News & Politics or Education; language English
- [ ] File name contains the search phrase
- [ ] Captions: upload the script-based SRT or review the auto captions
- [ ] End screen over the final 20 s: best-for-viewer video + subscribe; the Receipt line hands off to it
- [ ] Cards at about 20% and 70% of runtime, tied to a real moment in the script
- [ ] Pinned comment question ready
- [ ] `videos/<id>/licences.md` complete (guard blocks the pack without it)

## Gate
